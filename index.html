시선ON · 수업 신호 패널

설명을 볼 때, 변화를 볼 때, 직접 해볼 때를 명확하게.
한 기기에서 작동하는 모의 시연입니다. 교사 버튼과 학생 패널이 이 페이지 안에서 연결됩니다.

교사 진행 패널

학생 확인을 기다리고 있어요.

신호 전환 후 학생의 확인을 기다린 다음 설명·조작을 시작하세요. 확인 상태는 시선 감지나 이해도 판정이 아닙니다.

진행 기록

    학생용 신호 화면

    놓쳤다면 교사에게 다시 보기를 요청하세요. 교사는 학생마다 필요한 확인 시간을 제공합니다.

    발표 시연 방법과 실제 수업 적용 범위
    1. 교사가 ‘설명 확인’을 선택하고, 학생 역할로 ‘확인했어요’를 누릅니다.
    2. ‘변화 관찰’로 전환합니다. 확인 후 교사는 말을 멈추고 도형을 보여줍니다.
    3. ‘직접 해보기’ 확인 후, 실제 수업에서는 별도로 연 알지오매스 창에서 학생이 조작합니다.
    4. ‘이해 확인’에서 답을 선택합니다. 이 페이지의 문항과 피드백은 고정 예시이며 AI가 생성하지 않습니다.

    작은 패널 보기는 이 화면을 간소화할 뿐, 별도 창 생성·최상단 고정·다른 기기 연결 기능이 아닙니다. 노트북에서는 사용자가 창 크기를 조절해 알지오매스 옆에 배치할 수 있습니다. 패널을 놓칠 수 있으므로 학생의 확인 후 진행하는 절차가 필요합니다.

    실제 AI 활용은 소보로의 음성 인식 문자 지원입니다. 이 페이지 자체에는 녹음·계정·외부 전송·개인정보 저장 기능이 없습니다.
